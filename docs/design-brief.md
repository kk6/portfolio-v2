# Design Brief — Quiet Editorial

Status: Direction approved / Top page structure approved / Prototype in progress

## 1. Design Vision

**Quiet Editorial — 静謐なエディトリアル**

精密なタイポグラフィ、非対称な構図、余白、抑制された色彩によって、静かでありながら印象に残る個人ポートフォリオを目指す。

単にシンプルなだけのデザインではなく、細部の設計によって独自性を表現する。

## 2. 決定済みの方向性

### レイアウト

A-2「Asymmetric Editorial」を採用する。

- 日本語の文字組みを主役に据える。
- 非対称グリッドを基本とする。
- 余白とコンテンツ密度の対比を重視する。
- 作品画像を適切に組み合わせる。

### 情報設計

A-3「Dual Practice」の考え方を採用する。

- EngineeringとIllustrationの入口を明確にする。
- 両分野の違いを尊重しながら、一つの個人サイトとして統一する。
- 技術記事、OSS、開発プロジェクト、イラストなどを扱う。
- 具体的なページ構成やナビゲーション名は未決定。

### タイポグラフィ

- 日本語フォントの美しさを特に重視する。
- 和文と欧文の混植を丁寧に設計する。
- 字間、行間、ウェイト、行長、サイズの関係を検証する。
- 明朝体とゴシック体の両方を試作する。
- フォントは実際の日本語文章を使って比較する。

### 日本的な美意識

- 余白、非対称性、間、抑制などを重視する。
- 海外で表層的に解釈された「Zen」表現を安易に模倣しない。
- 毛筆文字のワンポイント使用は候補として残す。
- 竹、円相、墨の飛沫などを装飾目的で安易に採用しない。

### モーション

- 通常時は静かなデザインを保つ。
- ホバーやスクロールで控えめな変化を加える。
- 動きには意味や役割を持たせる。
- 過剰な3D表現や演出は避ける。
- アクセシビリティやreduced-motion設定を考慮する。

## 4. 初期プロトタイプ

### 基本構成

1. シンプルなヘッダーとナビゲーション
2. 日本語を主役とする非対称なヒーローセクション
3. 欧文タイポグラフィとの組み合わせ
4. EngineeringとIllustrationの明確な入口
5. Selected Worksへの導線
6. About / Contactへの導線

### 比較したい要素

- 和文ゴシックと和文明朝
- 欧文フォントとの組み合わせ
- 余白とグリッドの比率
- 色彩とアクセントカラー
- 作品画像の配置
- ホバー時の微細なインタラクション
- デスクトップとモバイルの表示

### プロトタイプの評価基準

- 独自性があるか
- タイポグラフィが美しいか
- 余白が意図的に設計されているか
- 情報の優先順位が明確か
- EngineeringとIllustrationの両方に自然にアクセスできるか
- 実際の作品が魅力的に見えるか
- 日本語の表示品質が高いか
- モバイルでも成立するか
- アニメーションが邪魔にならないか

### トップページの構成（2026-10-25 承認）

Impeccable の shape で候補を比べ、次の構成に決めた。詳細なブリーフは `.impeccable/surfaces/src-pages-index-astro.md` にある。

- 世界観は「作品に掛かる帯」とする。Quiet Editorial の中の表現として扱う。
- 作品を右寄りに、画面の高さいっぱいに置く。
- 作品の下部に全幅の帯を 2 本掛ける。上の帯は名前と Illustration の入口、下の帯は肩書きと Engineering の入口を載せる。
- スクロールに合わせて、2 本の帯が左右に分かれて外れ、作品の全体が現れる。この動きをサイトの署名とする。
- reduced-motion では動かさず、帯を作品の下に置いた完成状態を見せる。
- 外れた帯は、各セクションの見出しとして再び現れる（2026-10-25 承認）。Illustration の帯は去った左側から、Engineering の帯は右側から戻る。トップページは「ヒーロー → Illustration → Engineering → プロフィール」の順に並ぶ。「消える」「上部のナビに残る」は比べて見送った。
- 帯の色は作品に合わせる。作品から自動で取り出した色を基本とし、気に入らない作品だけ手で上書きする（2026-10-25 承認）。
  - 自動で取り出すときは、背景の白を除いて多い色から 2 色を選ぶ。
  - 彩度を抑え、帯が地から見分けられること（コントラスト 1.4 以上）と、帯の文字が読めること（4.5 以上）を保証する。
  - 本番では、サイトの生成時に 1 回だけ計算する。
  - 名前を載せる上の帯には、2 色のうち暗い方を置く（2026-10-25 承認）。作品は白い背景や明るい絵が多いので、暗い帯が名前と作品の下端を引き締める。手で上書きした色は、選んだ順のまま使う。

比べて見送った案：

- 乗換駅（2 路線のサイン計画）、函入りの二巻本、中心線の譜、美術館の展示室、即売会のカタログ、見開きの呼応、和文の版面、文芸誌の誌面。
- 帯の中の構成：縦の帯、帯を広げる、斜めの帯、帯が主役。「帯をずらす」と「2 本の帯」は、合成して採用した。

## 5. 未決定事項

- 具体的な和文・欧文フォント（2026-10-25 時点の第一候補。プロトタイプで比べた結果。ウェイトと商用書体との比較は未実施）
  - 見出し：和文 Zen Old Mincho、欧文 Spectral。
  - 短い本文（プロフィール、キャプションなど）：和文 Shippori Mincho、欧文 Spectral。
  - まとまった文章（技術ブログ、同人誌即売会への参加告知など）：和文 Zen Kaku Gothic New、欧文 Schibsted Grotesk。
- メインカラー、アクセントカラー
- ヒーローの作品（1 点固定寄りだが、ランダム表示も試してから決める）
  - アイデア（2026-10-25）：朝晩や季節に合わせて、ヒーローの作品を切り替える。表示中に一定間隔で切り替えるスライドショーは、画面がうるさくなるので採らない。
- 横長の作品をヒーローに置くときの配置
- ヒーローのコピー
- ロゴ・シンボル
- 作品の選定と掲載順序
- ナビゲーションの具体的な構成
- サイトの言語構成（日本語中心・英語併記・多言語対応）
- 具体的なモーション設計
- フレームワークとホスティングの最終決定

これらはAIが独断で確定せず、試作とユーザーの評価を通じて決める。
